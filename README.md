# Project Description

## Candidate Project 1
### Research Question
We want to investigate the use of an AI model to predict sleep apnea in adults using a combination of physiological measures from the [Respiratory and pulse oximetry waveforms form healthy adults during simulated apnoea events](https://physionet.org/content/respiratory-oximetry-apnoea/1.0.0/) dataset. 

### Biggest Uncertainty 
Our biggest uncertainty is the population diversity of the small sample, as well as the ecological validity of the data as all apnoeas were simulated and not true physiological events. 

### Biomedical Problem 
Our project aims to solve the issue of sleep disruption caused by respiratory complications, specifically sleep aponea. If successful in this project our software would provide early identification of subtle respiratory events that may predict sleep aponea, allowing for early intervention, encouragement of preventative measures and optimization of care.
